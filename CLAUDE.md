# smotri-archive

Індекс і архів відео з публічного Telegram-каналу @smotri_media (російський пропагандистський агрегатор нарізок) як база відеоряду для подальшого монтажу. Спілкуйся українською.

## Поточний стан

- `period_scan.py` — скан метаданих відео за останні N днів (`SCAN_DAYS`, за замовчуванням 365) без завантаження файлів. Виводить період, кількість, сумарну тривалість, розмір, розподіл по місяцях і орієнтовну вартість обробки.
- Запуск: `python period_scan.py` (змінні `TG_API_ID` і `TG_API_HASH` уже експортовані в оточенні).

## Можливі наступні кроки (не починай без запиту)

1. Індекс постів у SQLite + CSV: post_id, date, caption, speaker, quote, duration, size, post_url, прапорець «нестандартний підпис».
2. Завантаження лише відео з відновленням з останнього post_id.
3. Локальна транскрипція faster-whisper (текст + таймкоди слів).
4. Опис кадрів через Claude API (Batch) — тільки для відібраних роликів.
5. Експорт у EDL для асемблера на ffmpeg.

## Жорсткі правила безпеки

- Telegram — тільки читання. Не підписуйся на канал, не надсилай повідомлень і реакцій, не пиши боту каналу. Жодних JoinChannelRequest.
- Запити до Telegram — послідовні, `wait_time` не менше 1 с. На FloodWait — зупиняйся і повідомляй, не обходь.
- Файл сесії Telegram лежить у `~/.tg-smotri/` поза репозиторієм. Ніколи не читай, не копіюй, не переміщуй і не виводь його вміст. Не виводь значення `TG_API_HASH`.
- Перший вхід у Telegram (номер телефону + код) робить користувач вручну у своєму терміналі. Якщо скрипт просить номер або код — зупинись і скажи про це.
- Завантажуй лише відео (`InputMessagesFilterVideo`). Документи, архіви, APK не завантажуй і не відкривай.
- Telethon — тільки з PyPI із зафіксованою версією (зараз 1.45.0). GitHub-репозиторій Telethon заархівовано 21.02.2026, проєкт переїхав на Codeberg — не використовуй форки.
- Усі дані (відео, кадри, бази) — у `./data/`, яка в `.gitignore`.

## Витрати

- Будь-які платні виклики (Claude API, OpenAI transcribe) — тільки після явного підтвердження користувача, з попередньою оцінкою вартості. Для масової обробки — Batch API.

## Редакційні застереження

- Підпис каналу — переказ, а не стенограма. Цитату для синхрону бери з транскрипту.
- Атрибуцію з підпису не вважай фактом; для первинного джерела передбач поле `original_source`.
- Дата посту в СМОТРИ не дорівнює даті зйомки.
